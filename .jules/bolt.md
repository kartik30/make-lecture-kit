## 2024-06-25 - Word linting using single alternation regex in Python
**Learning:** Checking texts for many target words using multiple individual regex compilation and passes produces O(N*L) complexity. In `scripts/_plain_language.py`, creating pre-compiled regular expressions using alternations drastically reduced complexity down to O(L) on `find_fancy` and `find_handwaving` (which check the body of the generated PDFs and HTML). Sorting the keys by length descending is strictly necessary when joining dictionary keys into a regex pipe separated clause to prevent shorter phrases masking overlapping longer ones, and re-mapping outputs to prevent `KeyError` exceptions when lower-casing is used to count and sort output formats.
**Action:** When finding and tallying multiple discrete string patterns or phrases in texts, always build an alternation regex structure mapped back to variables for dictionary matching, which offers substantially better scale metrics than looping logic.
