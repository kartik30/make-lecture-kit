Introduction to Data Structures

A study kit on organizing information in a computer.

The big idea: Organizing Information

How we arrange data changes how fast we can find or change it. A data structure is a specific way to organize and store data.

Imagine a scavenger hunt vs a bookshelf. We will explore how computers do this.

Arrays: The Bookshelf

An array is the simplest data structure. It is a continuous block of memory divided into equal-sized slots, numbered in order.

Arrays are fast for looking things up if you know the index, but they are hard to resize.


Linked Lists: The Scavenger Hunt

A linked list is made of separate nodes. Each node holds data and a pointer to the next node.

Linked lists are easy to grow, but slow to search because you have to follow the pointers one by one.
